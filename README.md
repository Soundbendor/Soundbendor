# Soundbendor Lab website

Source for the Soundbendor Lab site at Oregon State University, built with Jekyll and
[al-folio](https://github.com/alshedivat/al-folio) v1.2 and deployed to GitHub Pages by GitHub Actions.

- Live site: https://www.soundbendor.org/ (published from `main`; `dev` pushes only build, as a check).
  Work on `dev`, then merge `dev` into `main` to publish.
- Pages: `_pages/`; news items: `_news/`; data: `_data/` (people, projects, funding, theme tags)
- Bibliographies in `_bibliography/` and files in `assets/pdf`, `assets/img` are generated by the lab's
  build pipeline (kept outside this repo) and copied in with `scripts/sync_site.py`. Edit the pipeline, not these copies.
- Local overrides of the al-folio theme: `_layouts/bib.liquid` (tags, Related, Archive button),
  `_includes/plugins/al_analytics_scripts.liquid` (GoatCounter), `assets/css/main.scss` + `_sass/_soundbendor.scss` (OSU colours).

## Contributing
Open a pull request against `dev`; the lab director reviews and merges.
